	6. this, sealed, static, partial and readonly keyword - Completed

	This - this referes to the current instance of a class. it's mainly used to differentiate between class fields and method parameter when they have the same name

	static - static members belongs to the class itselt, not to an object. which means you can access them without creating an object

	readonly - readonly fields can be assigned only once, either at declearation or in the constructor to make value unchangable.

	partial - this keyword is uded to split the defination of class , or interface into multiple file.

	why do we use??

	 1. to divide large classes into small managable pieces.
	 2. Helpfull in team env. where multiple developers work on the small class
