📝 Sample Coding Question (Math + String Combo)

> Q: Given a string of digits, write a C# program to calculate the sum of all digits.



// Input: "12345" -> Output: 15

✅ Answer:

string input = "12345";
int sum = 0;

foreach (char c in input)
{
    sum += c - '0'; // Convert char to int
}

Console.WriteLine("Sum of digits: " + sum);
